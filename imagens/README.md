# Imagens

Esta pasta contém as imagens referenciadas em `paletas.json`.

Você deve colocar aqui as suas imagens `foto-01.jpg`, `foto-02.jpg`, etc.
Caso alguma imagem não seja encontrada, a aplicação usará uma imagem de *fallback* SVG renderizada em tempo real (baseada na paleta de cores correspondente) para não quebrar a apresentação.
